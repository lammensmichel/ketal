# Story: 1.2 - Remove Player

**Status**: Done
**Epic**: Epic 1 - Player Management
**Created**: 2026-01-23
**Updated**: 2026-01-23

---

## Story

**As a** game host
**I want** to remove players from the game before it starts
**So that** I can correct mistakes or adjust the player list

---

## Acceptance Criteria

1. [x] **AC1**: Each player in the list has a delete button (X icon)
2. [x] **AC2**: Clicking delete removes the player from the list immediately
3. [x] **AC3**: localStorage is updated after player removal
4. [x] **AC4**: Delete button only visible when game is in "new game" state
5. [x] **AC5**: Summary mode is disabled if player count drops to 1 or below
