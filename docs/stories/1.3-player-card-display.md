# Story: 1.3 - Player Card Display

**Status**: Done
**Epic**: Epic 1 - Player Management
**Created**: 2026-01-23
**Updated**: 2026-01-23

---

## Story

**As a** player
**I want** to see my player card with avatar, name, and game information
**So that** I can track my predictions, drawn cards, and sip counts during the game

---

## Acceptance Criteria

1. [x] **AC1**: Player card displays avatar image (DiceBear) and player name
2. [x] **AC2**: Player card shows up to 4 card slots for predictions (phase 1)
3. [x] **AC3**: Each card slot displays the actual card image when a card is assigned
4. [x] **AC4**: Empty card slots show a card back placeholder
5. [x] **AC5**: Player card displays current sip count with color coding (positive=green, negative=red, zero=grey)
6. [x] **AC6**: Clicking sip badge opens modal to distribute sips (when applicable)

### Architecture Context
- Pattern: Standalone component composition (PlayerCard contains PlayingCard)
- Pattern: Service injection via `inject()` function
- Pattern: Event-driven modal opening via RxJS Subject
- Pattern: Conditional styling with ngClass directive
- Constraints: Exactly 4 card slots (game rule - 4 prediction rounds)
- Reference: CLAUDE.md - Modern Angular 19 Patterns

### Implementation Hints
- Card images stored in `assets/images/cards/svg/`
- Default card back: `assets/images/cards/svg/blue_back.svg`
- Sip count uses absolute value for display, sign for color
- Modal opens via `openSipGiveModalEvent$` observable subscription
- Cards accessed via index: `player.cards[i]`
