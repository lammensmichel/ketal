## Story

**As a** game host
**I want** to add players to the game with their names
**So that** I can set up a game session with all participants

---

## Acceptance Criteria

1. [x] **AC1**: User can enter a player name in an input field and submit to add the player
2. [x] **AC2**: Each player automatically receives a unique DiceBear avatar based on their UUID
3. [x] **AC3**: Player list is persisted to localStorage and restored on page reload
4. [x] **AC4**: Maximum of 23 players can be added (game rule limit)
5. [x] **AC5**: Form validation prevents empty/whitespace-only names

### Architecture Context
- Pattern: Standalone component with reactive forms
- Pattern: Service injection via `inject()` function (Angular 19)
- Pattern: DiceBear API for avatar generation using player UUID as seed
- Constraints: Max 23 players (half a deck per player for 4 cards each)
- Reference: CLAUDE.md - Modern Angular 19 Patterns

### Implementation Hints
- Player UUID generated via `uuid` npm package (v4)
- Avatar URL: `https://api.dicebear.com/7.x/avataaars/svg?seed=${playerModel.id}`
- Whitespace validation via `isNullOrWhiteSpace()` helper function
- Players stored in localStorage under key 'players' as JSON string
