## Failing Tests Analysis

### 1. AuthService Tests (Angular 20 Regression)

**Tests:**
- `AuthService logout should reset game state on logout` (spec.ts:272)
- `AuthService logout should clear all state even if Appwrite session deletion fails` (spec.ts:321)

**Error:**
```
Expected spy GameService.resetGame to have been called.
```

**Root Cause:**
After Angular 20 upgrade, the injected `GameService` is now `undefined` during test execution. The fix applied for NG0200 (circular dependency) introduced `@Optional() private gameService?: GameService;`, but the test mocks don't provide a mock GameService instance.

**Analysis:**
The AuthService now uses `this.getGameService()?.resetGame()` with optional chaining (correct runtime behavior), but the test spy doesn't spy on `undefined`:

```typescript
// Test provider:
mockGameService = jasmine.createSpyObj('GameService', ['resetGame']);
// ...
{ provide: GameService, useValue: mockGameService },
```

The inject works in production (service is provided at root level), but during test logout, the `gameService` is undefined.

**Fix:** The test needs to use `useClass` instead of `useValue`, or the spy should be provided via `GameService` token:

```typescript
{ provide: GameService, useValue: mockGameService },
```

This is already correct, but the issue is that `getGameService()` returns `undefined` because the `@Optional()` injection didn't work properly during test setup.

**Gravité:** **bloquant** - Cette régression est causée par la fix NG0200 elle-même (ajout de `@Optional`). Le test doit être corrigé pour provider correctement le mock.
