## Changes Applied

### Helper Imports Added

All files now import the exception helpers:

```typescript
import { isAppwriteException, getAppwriteErrorCode, getAppwriteMessage } from '../../_shared/helpers/appwrite-exception.helper';
```

### Error Handling Pattern

Before:
```typescript
catch (error) {
  throw new Error(`Failed to ...: ${error instanceof Error ? error.message : 'Unknown error'}`);
}
```

After:
```typescript
catch (error: unknown) {
  const appwriteError = getAppwriteMessage(error);
  if (isAppwriteException(error) && error.code === 404) {
    return null; // or appropriate fallback
  }
  throw new Error(`Failed to ...: ${appwriteError || (error instanceof Error ? error.message : 'Unknown error')}`);
}
```
