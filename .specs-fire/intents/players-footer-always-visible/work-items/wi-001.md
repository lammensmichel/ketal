# Work Item: Always-visible footer on /players during setup

## Context

Lines 367-382 in `footer.component.html` use two separate `@if` blocks:
- `hasPlayers()` → shows the start button panel
- `needsMorePlayers()` → shows a "minimum players" message panel

This causes layout shift as players are added/removed.

## Changes

### `src/app/_shared/_components/footer/footer.component.html` (DONE)
- Replace two `@if` blocks with a single `@if (gameSrv.isNewGame() && isPlayersPage())` block
- Inside: one `<div class="prediction-panel">` always rendered
- Button gets `[disabled]="!hasPlayers()"` instead of being conditionally rendered
- Minimum players hint shown as `<small>` with `visibility: hidden` when not needed (preserves layout)

### `src/app/_shared/_components/footer/footer.component.scss` (DONE)
- Add `.minimum-players-hint` rule with `visibility: hidden` variant to reserve space

## Acceptance Criteria

- [x] Footer panel is always visible on `/players` during setup (`isNewGame() && isPlayersPage()`)
- [x] Button is always rendered inside the panel
- [x] Button is disabled when ≤ 1 player, enabled when > 1 player
- [x] "Minimum players" hint text visible when ≤ 1 player, hidden (visibility) otherwise
- [x] Footer height stays constant regardless of player count
- [x] No regression on game footer behavior during active gameplay
