# Work Item: Écran de gestion des amis

## Description

Écran permettant à un utilisateur connecté de gérer sa liste d'amis (favoris).

## Acceptance Criteria

- [ ] Entrée « Mes amis » dans le side-menu, visible uniquement si connecté non anonyme.
- [ ] Liste des amis (avatar + pseudo) avec suppression.
- [ ] Ajout d'un ami par pseudo (champ de recherche) et par scan/affichage de QR code.
- [ ] États gérés : liste vide, chargement, erreurs (introuvable, déjà ami).
- [ ] i18n fr/en/de/nl ; responsive ; accessible (`aria-*`, focus).
- [ ] Composant standalone OnPush, route lazy (`loadComponent`).

## Technical Notes

- Réutiliser `FriendService` (wi-003) et les composants partagés (header, toast).
- Affichage du propre QR de l'utilisateur pour être ajouté par d'autres.
- Suivre le design system existant (story-15.1).
