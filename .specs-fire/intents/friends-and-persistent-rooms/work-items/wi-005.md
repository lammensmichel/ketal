# Work Item: Sélection d'amis + soi-même dans /players

## Description

Permettre, sur l'écran de mise en place des joueurs (`/players`), de sélectionner des
amis (dont soi-même) en plus de l'ajout d'invités libres. Les amis sélectionnés sont
référencés comme vrais joueurs (`game_members.userId`), les invités restent non
enregistrés (nom seul / `deviceId`).

## Acceptance Criteria

- [ ] Section « Amis » au-dessus de la liste des joueurs : chips toggle sélectionnables.
- [ ] « Moi » épinglé en premier, ajoutable/retirable comme joueur (avatar/nom du compte).
- [ ] Un ami sélectionné devient un joueur de la partie lié par `userId`.
- [ ] Le formulaire « invité libre » (gender picker + nom) reste inchangé (rétrocompat).
- [ ] Mélange amis + invités libres possible dans la même partie.
- [ ] Section « Amis » masquée pour les utilisateurs anonymes.
- [ ] i18n fr/en/de/nl ; responsive ; accessibilité (`aria-pressed` sur les toggles).

## Technical Notes

Layout cible (mobile-first) — voir aussi le brief :
```
Amis                       [ + Ajouter un ami]
[ Moi ✓ ] [ Léa ✓ ] [ Tom ] [ + + + ]   ← chips toggle
Invité libre (non enregistré)
[♂][♀][⚧] [ Nom du joueur… ] [Ajouter]    ← inchangé
Joueurs de la partie (N)                   ← tiles app-player-list-player existantes
```
- Réutiliser `FriendService` (wi-003) et `app-player-list-player`.
- S'appuyer sur le member hôte/room de wi-001 pour rattacher les joueurs.
