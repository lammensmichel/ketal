# Work Item: FriendService (frontend) — favoris, recherche pseudo + QR

## Description

Service Angular pour gérer les amis (favoris unilatéraux) côté frontend, s'appuyant sur
la collection `friendships` et le `nickname` introduits en wi-002.

## Acceptance Criteria

- [ ] `FriendService` (standalone, `inject()`, signals) avec :
      `getFriends()`, `addFriendByNickname(nickname)`, `addFriendByQr(payload)`,
      `removeFriend(friendUserId)`.
- [ ] Recherche d'un utilisateur par `nickname` (exact/préfixe) via Appwrite.
- [ ] Génération + parsing d'un QR code identifiant l'utilisateur (réutiliser
      `angularx-qrcode` déjà présent).
- [ ] Gestion des erreurs (utilisateur introuvable, déjà ami, soi-même).
- [ ] Tests unitaires en mode mock (couverture ≥ 80 %).

## Technical Notes

- Réutiliser `AppwriteService` + le pattern des autres services (`RoomService`/`MemberService`).
- QR : encoder l'`userId` (ou un code dérivé) ; décodage à l'ajout.
- Favoris unilatéraux → pas de notion d'acceptation.
