# Story Draft Checklist

## Story Structure
- [ ] Clear user story format (As a... I want... So that...)
- [ ] Story is linked to epic
- [ ] Story has unique identifier

## Acceptance Criteria
- [ ] All acceptance criteria are testable
- [ ] Criteria are specific and measurable
- [ ] Edge cases are considered
- [ ] No ambiguous language

## Size and Scope
- [ ] Story is appropriately sized (2-4 hour AI session)
- [ ] Story delivers incremental value
- [ ] Story is independently completable
- [ ] No hidden complexity

## Context Engineering
- [ ] Relevant files are listed with line numbers
- [ ] Architecture context is included
- [ ] Implementation hints provided
- [ ] Angular 19 patterns specified

## Dependencies
- [ ] Blocking stories identified
- [ ] Blocked stories identified
- [ ] No circular dependencies
- [ ] Prerequisites are clear

## Testing Requirements
- [ ] Unit test scenarios defined
- [ ] Edge cases documented
- [ ] Test coverage expectations clear

## Technical Completeness
- [ ] API changes documented
- [ ] Data model changes noted
- [ ] UI/UX requirements clear
- [ ] Error handling expectations

## Ketal-Specific
- [ ] Uses signals for state changes
- [ ] Standalone component pattern
- [ ] OnPush change detection
- [ ] Socket.IO events if real-time
- [ ] i18n keys if user-facing text

## Ready for Development
- [ ] Story can be understood without asking questions
- [ ] Developer can start immediately
- [ ] All resources referenced exist
- [ ] No missing information
