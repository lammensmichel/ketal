# Change Request Checklist

## Change Classification
- [ ] Determine change type: Bug Fix | Enhancement | New Feature | Refactor
- [ ] Assess impact: Low | Medium | High
- [ ] Identify affected areas

## Analysis
- [ ] Root cause identified (for bugs)
- [ ] Requirements clear
- [ ] Scope defined
- [ ] Risks assessed

## Documentation Impact
- [ ] PRD update needed?
- [ ] Architecture update needed?
- [ ] Story creation needed?
- [ ] CLAUDE.md update needed?

## Planning
- [ ] Effort estimated
- [ ] Dependencies identified
- [ ] Priority assigned
- [ ] Assigned to appropriate agent

## Implementation Path

### Minor Changes (Bug fixes, small tweaks)
- [ ] Create implementation tracking file
- [ ] Implement fix
- [ ] Test
- [ ] Review
- [ ] Deploy

### Medium Changes (Enhancements)
- [ ] Update relevant documentation
- [ ] Create story if needed
- [ ] Implement
- [ ] Test
- [ ] Review
- [ ] Deploy

### Major Changes (New features)
- [ ] Create/update PRD
- [ ] Architecture review
- [ ] Create stories
- [ ] Implement iteratively
- [ ] Test thoroughly
- [ ] Review
- [ ] Deploy

## Validation
- [ ] Acceptance criteria met
- [ ] Tests passing
- [ ] No regressions
- [ ] Documentation updated

## Closure
- [ ] Change verified in target environment
- [ ] Stakeholder sign-off
- [ ] Implementation file moved to completed
- [ ] Lessons learned captured
