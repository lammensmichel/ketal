# Product Manager PRD Checklist

## Prerequisites
- [ ] Project brief exists or created
- [ ] Analyst research completed
- [ ] Stakeholder input gathered

## Goals Section
- [ ] Goals are specific and measurable
- [ ] Success criteria defined
- [ ] Business value articulated

## Requirements
- [ ] All functional requirements captured
- [ ] Non-functional requirements addressed
- [ ] Requirements are prioritized
- [ ] No conflicting requirements

## User Experience
- [ ] User personas identified
- [ ] User journeys documented
- [ ] UI/UX goals clear
- [ ] Accessibility considered

## Technical Section
- [ ] Technical assumptions validated
- [ ] Constraints documented
- [ ] Dependencies identified
- [ ] Integration requirements clear

## Epic Structure
- [ ] Epics are logically organized
- [ ] Each epic delivers value
- [ ] Epic dependencies mapped
- [ ] Priority order defined

## Story Quality
- [ ] Stories follow proper format
- [ ] Acceptance criteria are testable
- [ ] Stories are appropriately sized
- [ ] No gaps in coverage

## Risk Management
- [ ] Risks identified
- [ ] Impact assessed
- [ ] Mitigations defined
- [ ] Out of scope clearly stated

## Completeness
- [ ] All sections completed
- [ ] No TBD items remaining
- [ ] Consistent terminology
- [ ] No contradictions

## Review
- [ ] Self-review completed
- [ ] Technical review with architect
- [ ] Stakeholder review
- [ ] PO validation

## Approval
- [ ] All reviewers signed off
- [ ] PRD status updated to Approved
- [ ] Ready for architecture phase
