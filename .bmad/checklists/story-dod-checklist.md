# Story Definition of Done (DoD) Checklist

## Implementation
- [ ] All acceptance criteria are met
- [ ] Code follows established patterns
- [ ] No console errors or warnings
- [ ] Feature works as specified

## Code Quality
- [ ] Code is clean and readable
- [ ] No code duplication
- [ ] Proper error handling
- [ ] No hardcoded values (use constants/config)

## Angular 19 Compliance
- [ ] Uses signals for reactive state
- [ ] Component is standalone
- [ ] OnPush change detection enabled
- [ ] New control flow syntax (@if, @for, @switch)
- [ ] inject() for dependency injection
- [ ] Proper typing (no `any`)

## Testing
- [ ] Unit tests written and passing
- [ ] Edge cases tested
- [ ] Coverage threshold met (80%)
- [ ] No flaky tests

## Documentation
- [ ] Code is self-documenting
- [ ] Complex logic has comments
- [ ] i18n keys for user-facing text
- [ ] Story record updated

## Security
- [ ] Input validation implemented
- [ ] No XSS vulnerabilities
- [ ] No sensitive data exposed
- [ ] Proper authentication checks (if applicable)

## Performance
- [ ] No unnecessary re-renders
- [ ] Efficient data handling
- [ ] No memory leaks
- [ ] Lazy loading where appropriate

## Integration
- [ ] Works with existing features
- [ ] Socket.IO events tested (if applicable)
- [ ] No breaking changes to APIs
- [ ] Backend compatibility verified

## Review
- [ ] Self-review completed
- [ ] Code review passed
- [ ] QA review passed
- [ ] Demo ready (if required)

## Deployment
- [ ] Builds without errors
- [ ] Linting passes
- [ ] Works in production build
- [ ] No console errors in prod mode

## Story Closure
- [ ] Story status updated to Done
- [ ] Dev agent record completed
- [ ] QA results documented
- [ ] Any follow-up tasks created
